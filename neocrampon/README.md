# Sainte Bible néo-Crampon Libre

Modernisation de la traduction catholique française de Crampon.

- **Traduction** : Sainte Bible néo-Crampon Libre, © 2022 Fraternité de Tibériade.
- **Source** : [eBible.org](https://ebible.org/) — module `francl`
  (`https://ebible.org/Scriptures/francl_usfm.zip`).
- **Contenu** : 66 livres (canon protestant), 1 189 chapitres, 31 164 versets.
  Les livres et ajouts deutérocanoniques ont été retirés.
- **Format** : schéma getbible.net (texte nu), un fichier par livre :
  `https://raw.githubusercontent.com/victordiaz1000/-bym-bibles/main/neocrampon/{n}.json`
